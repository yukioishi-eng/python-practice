# Python Architecture & Data Analysis Showcase

Pythonの基礎・オブジェクト指向・ドメイン駆動設計（DDD）の実践から、データ分析・自動化処理までを体系的に網羅したポートフォリオです。

単に「動くコードを書く」だけでなく、「保守性・拡張性の高い設計の追求」および「データドリブンな問題解決力」を軸に、設計判断の意図をコードとログに残しながら実装を進めています。

---

## 🎯 ハイライト（アピールポイント）

- ドメイン駆動設計 (DDD) の実践: 集約ルート（Aggregate Root）による不変条件の保証や、ドメインイベントによる副作用の分離を実装。
- 堅牢な状態管理: 状態遷移テーブル（`ALLOWED_TRANSITIONS`）と `Enum` を用いたテーブル駆動設計により、不正な遷移を堅牢に防ぐ構造の構築。
- データ分析・データ処理の実践: `data_analysis` モジュールにおけるデータ抽出・集約・加工処理の実装と自動化。
- テスタビリティと可読性の向上: レイヤードアーキテクチャの導入、Repository パターンの抽象化、型ヒント・docstring の徹底。
